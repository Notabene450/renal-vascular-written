# Renal vascular diseases · written questions (SAQ)

صفحة واحدة (ملف HTML واحد) فيها **48 سؤال Written SAQ** على محاضرة Renal Vascular Diseases، مقسومة على 6 أقسام.

## إزاي تفتحها
- على جهازك: من زرار **⬇ download the file** اللي فوق الصفحة، أو نزّل `index.html` وافتحه بالدبل كليك (مفيش نت مطلوب).
- على النت: `https://notabene450.github.io/renal-vascular-written/`

## المميزات
- كل سؤال: *Mention the two / three / four / five / six …* — طلب واحد، من 2 لـ6 نقاط، والنقاط 1–3 كلمات.
- زر 👁 الإجابة المثالية لكل سؤال، وزر 🤖 تصحيح بالـAI (Gemini، وGroq اختياري للسرعة).
- لوحة كتابة بالقلم (stylus) — القراءة إنجليزي فقط.
- بحث بالكلمات + فهرس + عدّاد الأسئلة الغلط.
- زرار A± للتكبير والتصغير، وخط صغير يناسب أضيق شاشة تليفون.
- إجاباتك بتتخزن في المتصفح نفسه (localStorage) — مفيش أي رفع لسيرفر.

## الأقسام
Renal artery stenosis · Renal vein thrombosis · Athero-embolic disease · Thrombotic microangiopathy · HUS, TTP & HELLP · Antiphospholipid syndrome
